# ionutcm.com

Website for apps by ionutcm: product pages, support, privacy policies and terms.
Plain HTML and CSS, generated by one Python script (standard library only). No framework, no tracking.

## How it works

| Folder | What's in it |
|---|---|
| `content/apps.json` | **Every app**: name, tagline, description, screenshots, features, platforms and store links, legal pages, support answers |
| `content/legal/` | Privacy and terms wording for each app, plus the website privacy page |
| `src/static/` | Stylesheet, script, screenshots, icons, `_redirects`, `_headers` |
| `tools/build.py` | Builds the whole site into `public/` |
| `tools/serve.py` | Local preview that behaves like Cloudflare |
| `public/` | The built site. Cloudflare publishes this folder (see `wrangler.jsonc`) |

Build and preview:

```
python3 tools/build.py
python3 tools/serve.py      # http://localhost:8080
```

Commit `public/` together with your change: Cloudflare doesn't run the build.

## Adding an app

1. Take screenshots of the real app at 390 × 844 (phone size), light and dark. Save each as WebP at 780 × 1688 **and** 480 × 1037 in `src/static/assets/screens/`, named `<id>-light.webp`, `<id>-dark.webp`, `<id>-light-480.webp`, `<id>-dark-480.webp`.
2. Add an entry to `content/apps.json` (copy an existing one). Set `order` for its position and `published: true` when ready.
3. Write `content/legal/<slug>-privacy.html` and `<slug>-terms.html`, and point `legal` in the entry at `/<slug>-privacy` and `/<slug>-terms`.
4. Run `python3 tools/build.py`. The home page, Apps page, app page, support, footer and sitemap update by themselves. The build stops if a screenshot is missing.

### Platforms and store buttons

For each of `android` and `ios`, `status` is one of:
- `available` with a real `url` → a store button is shown
- `coming-soon` → "Coming soon" is shown, never a button
- `none` → the platform isn't mentioned

Never add a store link until the app is actually live there.

### App icons

Until real icons exist, each app shows a monogram (`monogram`). To use a real icon, put a square PNG in `src/static/assets/icons/` and set `"icon": "/assets/icons/<slug>.png"`.

## Addresses

The old `/my-money` page redirects to `/apps/my-money` (`src/static/_redirects`). Privacy and terms addresses used in Play Console and App Store Connect stay the same:
`/my-money-privacy`, `/my-money-terms`, `/habit-dial-privacy`, `/habit-dial-terms`, `/support`.
