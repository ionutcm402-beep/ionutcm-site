Website privacy

Last updated 7 November 2026 · Covers this website only. Each app has its own privacy policy, linked below.

In short: this website has no cookies, no analytics, no tracking, no forms and no accounts.

What this website collects

Nothing is collected by the website itself. It is a set of static pages. It does not set cookies, use analytics or advertising, or load fonts or scripts from other companies.

Hosting

The website is hosted by Cloudflare. Like any web host, Cloudflare processes technical information such as your IP address to deliver pages and protect the site from abuse. See Cloudflare's privacy policy.

Emailing us

If you email contact@ionutcm.com, the message is delivered to our mailbox. We use your email address and message only to reply, and delete the conversation when it is no longer needed, at the latest after 2 years.
